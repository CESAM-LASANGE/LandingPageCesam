# Evals

Diretório reservado para fixtures, casos de regressão, referências visuais e verificações de acessibilidade.

- `regression/`: bugs reais convertidos em casos permanentes.
- `visual/`: referências e configuração de comparação visual.
- `accessibility/`: cenários e verificações adicionais de acessibilidade.

Evitar armazenar aqui prompts vagos. Cada eval deve declarar objetivo, entrada, critério e condição de aprovação.
