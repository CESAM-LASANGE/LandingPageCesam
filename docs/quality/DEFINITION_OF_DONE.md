# DEFINITION OF DONE

Uma feature só está Done quando:

- [ ] Existe spec suficiente para eliminar ambiguidades críticas.
- [ ] Todos os critérios de aceite foram verificados.
- [ ] Código está dentro do escopo.
- [ ] Typecheck passa.
- [ ] Lint passa.
- [ ] Testes aplicáveis passam.
- [ ] Build de produção passa.
- [ ] Responsividade foi validada.
- [ ] Acessibilidade foi validada no nível aplicável.
- [ ] SEO/metadados foram tratados quando relevantes.
- [ ] Não há regressão visual não aprovada.
- [ ] Não foram introduzidos segredos ou dados sensíveis.
- [ ] Review independente foi realizado quando exigido.
- [ ] Documentação afetada foi atualizada.

`Done` descreve evidência, não confiança subjetiva do implementador.
