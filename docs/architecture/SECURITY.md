# SECURITY

## Baseline

- Não expor segredos no cliente ou repositório.
- Validar entradas em qualquer formulário.
- Minimizar coleta de dados pessoais.
- Aplicar princípio de menor privilégio às integrações.
- Manter dependências atualizadas de forma controlada.
- Configurar headers de segurança adequados à stack.
- Evitar HTML arbitrário não sanitizado.

## Privacidade

Qualquer analytics, formulário ou integração que processe dados pessoais deve ser avaliado quanto à necessidade, transparência e requisitos legais aplicáveis antes da implementação.

## Gate

Vulnerabilidades críticas/altas conhecidas introduzidas pela mudança bloqueiam merge até análise e tratamento.
