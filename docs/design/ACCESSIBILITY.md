# ACCESSIBILITY

## Meta

Adotar WCAG 2.2 nível AA como referência de engenharia, salvo requisito institucional mais rigoroso.

## Requisitos-base

- HTML semântico.
- Hierarquia coerente de headings.
- Navegação completa por teclado.
- Foco visível.
- Contraste adequado.
- Texto alternativo útil para imagens informativas.
- Imagens decorativas corretamente ignoradas por tecnologia assistiva.
- Labels e mensagens de erro acessíveis em formulários.
- Respeito a preferências de redução de movimento quando aplicável.

## Validação

Combinar automação com revisão manual. Uma ferramenta automática não prova conformidade integral.
