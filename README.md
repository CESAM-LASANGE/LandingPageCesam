# Site Institucional da Fundação — Foundation Pack

Este repositório reúne a documentação inicial para desenvolvimento do site institucional da Fundação com IA no loop.

## Princípios

- Spec-Driven Development (SDD)
- Eval-Driven Development (EDD)
- Test-Driven Development (TDD)
- Context Engineering
- Quality Gates
- Autonomia Progressiva

## Regra central

Nenhuma feature é considerada concluída porque um agente declarou que terminou. A conclusão depende dos critérios de aceite, testes, evals e quality gates definidos no projeto.

## Fluxo

Ideia → requisito → spec → critérios de aceite → testes/evals → plano → implementação → validação → review independente → review humano → merge.

## Estado

Fase 0 — documentação-base. Os campos marcados como `TODO` devem ser preenchidos após análise do design aprovado e levantamento institucional.
